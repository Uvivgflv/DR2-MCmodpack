# Minecraft Modpack - KubeJS Development

## Команды разработки WIP

```bash
# Форматирование кода
npm run format

# Проверка качества кода
npm run lint

# Деплой в игровой инстанс
npm run deploy

# Бекап проекта
npm run backup

# Работа с Git
npm run git:status
npm run git:commit -- "сообщение"
```
