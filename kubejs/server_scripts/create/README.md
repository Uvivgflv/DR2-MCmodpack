# Create Mod Scripts

Этот каталог содержит скрипты KubeJS для модификации рецептов модуля **Create** и **Greate**.

## Что находится в файлах:

### `recipes.js`
Основной файл для управления рецептами Create/Greate.
- **Удаление рецептов** — отключение стандартных рецептов модов
- **Добавление новых рецептов** — создание пользовательских рецептов
- **Поддержка всех типов рецептов** Create (прессование, смешивание, резка и т.д.)

### `compat.js`
Файл совместимости с другими модами.
- Специальные рецепты для взаимодействия Create с другими модулями
- Рецепты смешивания с другими модами
- Рецепты совместимости GTCEU и других модов

### `tags.js`
Регистрация пользовательских тегов и массивов предметов.
- Определение переменных для групп предметов
- Создание тегов для более удобного использования в рецептах
- Упрощение повторного использования наборов предметов

### `crossRecipes.js`
Кроссмод рецепты и интеграция.
- Рецепты, связывающие Create с другими модами
- Специальная логика обработки рецептов

### `sequenseAssemblyVanilla.js`
Рецепты поэтапной сборки ванильных предметов.
- Интеграция Create Assembly с ванильной игрой
- Механизированные рецепты для стандартных крафтов Minecraft

## Как использовать:

1. Редактируйте нужный файл в соответствии с типом изменений
2. Используйте переменные из `tags.js` в других файлах для консистентности
3. Сначала удаляйте старые рецепты, потом добавляйте новые
4. Проверяйте логи сервера при загрузке скриптов
